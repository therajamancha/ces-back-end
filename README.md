# CES Backend Service

Simple Node.js & Express API template.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server (with auto-reload):
   ```bash
   npm run dev
   ```

3. Start production server:
   ```bash
   npm start
   ```

## Endpoints

- `GET /` - API welcome info
- `GET /health` - Health check status
